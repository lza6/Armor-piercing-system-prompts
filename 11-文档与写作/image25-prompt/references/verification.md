# 验收与公平对照

这是本项目的人工检查方法，不是自动模型测评。

| 任务 | 优先检查 | 最小修复方向 |
|---|---|---|
| 中文海报 | 拼写、标点、遗漏、重复、层级 | 固定版式，只修指定文字块 |
| 产品 | 结构、比例、标识、反射 | 回母图，仅改指定环境或表面 |
| 人物 | 身份特征、年龄感、脸和手 | 用身份参考修局部 |
| 持物 | 人物左右、接触、遮挡 | 说明机位投影或用姿势草图 |
| 改色 | 颜色、纹理、非目标区域 | 限定颜色变化范围 |
| 透明 | alpha、白边、半透明边缘、假棋盘格 | 检查实际文件，不只看白底预览 |
| 信息图 | 数字、箭头、图例、关系 | 先修事实结构 |
| 系列 | 身份、品牌、物件和状态 | 最近通过版本恢复 |

有alpha通道不等于存在透明像素。无文件检查能力时说明只做视觉检查。

## 报告

给具体可见问题，不给无依据的95分或提升30%。分开已完成、未完成、无法判断的要求，再给最小修改。不把没发现错误说成像素完全一致，不把审美偏好当成服从指令。

## 对照设计

提示词实验尽量固定工具和输入，只改变写法。工具版本未公开时说明后端无法完全控制。
模型实验固定完整提示词、参考、尺寸、共享质量档、格式，只切换可核实的模型。
每组样本数相同，保留失败；单样本只作探索，无token或账单信息不报实际费用。

局部编辑两组用同一母图。多轮实验各组使用各自上一轮输出，保留共同起点，不中途只给某组换优质参考。
