# 编辑与连续性

## 输入职责

参考创作借用身份、风格或构图生成新画面；局部编辑保留已有画面，只改变目标。
“保持原图”与“完全重构图”同时出现时，先判断用户最重要的目标。
查看实际图后再识别可见特征，不凭空写出眼睛颜色、商品文字或衣物结构。

## 编辑骨架

```text
编辑目标：输入图1。
本次只修改：
保留人物：
保留物体与接触：
保留构图、背景、光线：
边缘与材质处理：
```

只列有意义的保留项。改灯光允许阴影和反射变化；换服装款式允许轮廓变化。不能要求换夜景却全图光照不变。

## 多图分工

例：图1身份，图2服装，图3房间。
先决定机位，检查房间透视支持站位。明确服装图不负责脸和身材，房间图不负责服装。
固定商品或人物时从同一母图派生版本，避免把失真生成图作为唯一身份参考。

## 多轮记录

用户需要追溯或项目较复杂时，可记录：
```json
{
  "version": "v02",
  "parent": "v01",
  "reference_roles": {"image1": "edit target", "image2": "identity reference"},
  "change": "只替换外套颜色",
  "preserve": ["身份", "双手接触", "构图"],
  "status": "pending_review",
  "observed_issues": []
}
```
这是本项目记录格式，不是API参数；简单一次编辑不强制建文件。

选通过版本 → 单一目标或紧密相关修改 → 看结果 → 接受或回退。
反复失败时减少冲突、换清晰参考或说明缺陷，不无限重试。未约定上限时，可建议两次针对性修复后汇报；用户已有次数或预算则遵循其约定。

## 草图、批注、遮罩

它们帮助定位意图，支持程度取决于工具。草图可负责位置、大小、视线和遮挡；明确箭头或编号只是说明，不进入成品。
只有实际提交遮罩才能说使用了遮罩。严格的像素保留应考虑把接受的局部结果合成回原图，不能靠“保持不变”保证。

## 人物检查

对比脸轮廓、痣、发际线、年龄感和肤色，再检查衣服修改是否影响手和姿态。更好看的脸不能默认替代身份参考。

区分同图编辑、同角色新镜头、多轮连续编辑。前者固定机位，第二种允许透视和可见部分变化，第三种会累积误差；不能拿不同任务结果宣称同一种能力提升。
