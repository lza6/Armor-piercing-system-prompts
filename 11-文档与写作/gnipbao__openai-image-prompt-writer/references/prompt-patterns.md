# 按任务选择提示词结构

以下均为本技能的原创结构，不是模型要求的特殊语法。只保留本次必要字段；没有变量的成品不应残留方括号占位符。

## 新建图像

适合摄影、插画、海报底图、商品场景。先写主体，再写空间关系；短任务可合并成一段。

```text
为[用途]创作一张[媒介/图像类型]，画面比例为[比例]。
主体是[数量、外观与动作]，位于[位置]；[配角或背景]与主体的空间关系为[关系]。
构图采用[取景、视角、视觉层级]；为[后续用途]在[区域]保留空白。
光源为[方向、软硬和色温]，关键材料呈现[表面特征]，配色为[主色与辅助色]。
[只有确有需要时加入精确文字及禁止项。]
```

## 局部编辑与换装

适合移除物体、换衣服、换家具、翻译画中文字。输入图已存在时引用实际图像；仅写作且未附图时说明这是待提供的图。

```text
编辑图 1，只把[明确对象/区域]从[原状态]改为[目标状态]。
保持[身份外观/轮廓/几何/标签/构图/机位/其他物体]不变。
新内容应符合原图的[透视、照明、接触阴影、材质尺度]。
允许因本次修改自然改变的部分仅为[范围]；不要扩展到[非目标区域]。
```

先处理矛盾：换家具会改变家具自身阴影，可以保留房间总体照明和未编辑物体的阴影，不要求改变物体同时让其旧阴影丝毫不动。要改变姿势，就不能把原姿势列为保留项。

翻译需要核对全部待替换文字、目标语种与保留品牌名，保持版式、图形和颜色；不把“只翻译文字”理解成可以删掉难放下的文本。

## 多图融合与风格迁移

输入次序先确定，随后锁定每张图的职责。风格参考不自动授权复制其中的主体、文字或 Logo。

```text
图 1 是[底图/人物/产品]，提供[需要保留的内容]。
图 2 仅提供[风格/服装/背景/配色]，不带入[无关元素]。
将[指定来源的元素]放在[目标位置]，与[已有对象]形成[大小、遮挡或互动关系]。
以图 1 的[身份、几何、版式等]为准；以图 2 的[色彩、材质等]为准。
使光线、透视、清晰度和接触阴影协调，保持[关键约束]。
```

超过两张图时逐张增加必要职责，不猜测用户未说明的对应关系。实际融合时必须提交全部必要输入。

## 精确文字与中文海报

```text
在[画面区域]排入以下文字，各出现一次，保留每一个字及标点：
主标题：“[原文]”
副标题：“[原文]”
主标题采用[字体类别、粗细、层级与对齐]，副标题采用[层级]。
文字区与主体之间留有[空间要求]，保证可读性且不遮挡[关键对象]。
除以上文字与明确要求保留的产品标签外，不添加其他文字。
```

若只要后期排版用的无字底图，改为“该区域只留白，不生成任何文字”。不要同时要求精确标题与无字画面。数字、单位、大小写及中文标点均属于原文的一部分。

## 信息图、图表与教学图

先取得内容，再安排视觉关系。没有真实数据时索取数据，或交付清楚标记的待填模板；不要自行凑出貌似真实的市场规模与引用。

```text
为[受众]制作一张[比例]的[图表/流程图/教学图]，帮助读者理解[一个目标]。
必须包含这些节点/数值/标签：[用户数据或已核验内容]。
关系为：[起点 → 终点及箭头意义]；单位与图例为[内容]。
采用[网格、阅读顺序、色彩编码]，保持文字清晰、箭头方向明确和足够留白。
只使用给定内容，不自行补充数字、来源或因果关系。
```

交付是图像，生成后仍需验证数值、箭头、标签、比例和单位。如果用户需要准确可编辑图表，交给数据绘图或演示文稿流程。

## UI 与幻灯片图像

像描述已经上线的产品那样写布局、内容、间距、导航和视觉层级。只在用户要求时加入设备外框；一张设计图不代表交付了可交互应用。

```text
制作一张[产品/页面]的[移动端界面/演示文稿页面]图像，比例[比例]。
信息优先级为[一级信息 → 二级信息 → 操作入口]。
实际显示内容为[给定文案/数据]，区域布局为[位置与大小关系]。
使用[背景、字体类别、间距和强调色]，呈现完整、可读的成品界面。
```

## 角色系列与漫画

先建立可重复引用的角色外观，随后每一张使用同一锚点。别只说“保持同一个人”。

```text
使用图 1 的角色外观：保持[脸部特征、身体比例、服装、配色和识别物]。
本张/本格发生：[一个可画出的动作]。
场景与镜头：[环境、取景、阅读顺序]。
维持[绘画媒介、线条、色彩关系]，只改变本张明确指定的情节与环境。
```

漫画写明格数、排列与阅读方向，每格一个关键动作。系列中的新姿势可变化，身体识别特征和约定服装应重复注明。

## 透明素材

提示词说明对象完整轮廓和透明背景；参数与文件验收另做。白色背景、画出来的棋盘格、扩展名为 PNG 都不等于透明。

```text
从图 1 分离出[对象]，保留[几何、颜色、标签]。
对象[位置与留白]，完整保留边缘；画面背景完全透明。
不画实体底色或棋盘格，清理边缘杂色，不添加[确实不需要的阴影或场景]。
```

透明头发、玻璃和半透明阴影需要检查边缘 alpha；后续编辑也应重申透明要求。

## 单轮修正

```text
以上一张结果为输入，只修正[一个具体失败点]为[可检查的目标]。
保持已经正确的[主体、身份外观、构图、标签或颜色]。
```

优先修复观察到的失败，不用一串新的审美形容词重新设计整张图。
