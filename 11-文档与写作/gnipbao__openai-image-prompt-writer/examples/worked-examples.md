# 原创使用示例

以下是文本写作示例，所有品牌与统计数据均为演示输入。没有随附参考图，也没有生成图片；涉及图 1/图 2 的请求在实际编辑前必须附上对应素材。

## 1. 中文海报，只要提示词

用户：

> 为虚构咖啡店“半日”写一个 3:4 竖版海报提示词。主标题“给自己半日闲”，副标题“桂花拿铁，秋日限定”，杯子在右下，左上排字，奶油白和桂花黄。只要最终提示词。

交付：

```text
为虚构咖啡店“半日”创作一张 3:4 竖版桂花拿铁海报。整体使用奶油白底色和少量桂花黄，画面安静、明亮，有充足留白。

一杯桂花拿铁位于画面右下方，陶瓷杯呈温润的哑光质感，奶泡表面点缀少量金黄色桂花。柔和日光从左侧照入，杯子下方保留轻淡自然的接触阴影。

左上方为独立文字区。主标题“给自己半日闲”完整出现一次，深棕色粗体中文字体，字号明显大于副标题；下方副标题“桂花拿铁，秋日限定”完整出现一次，字距舒展。标题与杯子之间留出清楚的空间，不相互遮挡，文字距离画面边缘至少保留一字宽。

只出现以上主标题和副标题，不另外添加店名、价格、英文、装饰性文字或水印。
```

说明：品牌名是场景输入，用户只指定两行画面文案，因此不擅自多排第三行。用户若指定店名必须可见，就将它加入精确文字清单。

## 2. 产品局部编辑，标签不能变

用户：

> 我会上传一张标有“ORB 30”的水杯产品图。帮我写编辑提示词，只把背景换成深蓝色，杯子和标签保持原样。

交付：

```text
编辑图 1，只将产品后方的背景替换为均匀的深蓝色。
保持水杯的外形、尺寸比例、颜色、材质、表面细节及“ORB 30”标签的文字、位置、清晰度不变；保持原图的产品位置、机位、裁切和产品照明。
背景与产品轮廓自然衔接，保留支撑水杯的接触关系；不要重新设计杯子、重绘标签或添加其他物体与文字。
```

输入说明：按用户描述编写；执行时需附产品图。本示例没有假装已看到杯子的具体材质或颜色。

## 3. 多图融合：人物与风格分工

用户：

> 图 1 是我的虚构角色设定，图 2 是一张木刻插画。写提示词让这个角色坐在树下读书，采用图 2 的视觉风格；别复制图 2 的人物与文字。

交付：

```text
以图 1 为角色外观参考，保留其面部特征、发型、身体比例、服装轮廓及识别性配色。
图 2 只作为木刻插画的线条、纹理和明暗组织参考，不取用其中的人物、文字、标志或具体场景。

让图 1 的角色坐在一棵树下的矮凳上，双手自然托着展开的书，视线落在书页上；书页只呈现简洁纹理，不生成文字。角色是画面视觉中心，树干位于左侧，疏朗树冠形成遮荫，完整保留角色与书的轮廓。

用图 2 的木刻线条和刻痕组织阴影，同时以图 1 的角色外观为准。保持人体、书本和座椅的透视与接触关系自然，不引入图 2 的其他内容。
```

输入说明：执行时按角色图、风格图的顺序提交两张图片；本例只定义引用规则。

## 4. 透明图标与单独的参数

用户：

> 给“纸舟”读书会设计一个无字透明图标，像折纸小船，方形。给提示词和 Image API 参数，优先快速出稿。

提示词：

```text
创作一个原创折纸小船图标，1:1 方形画面。用简洁的几何折线与浅蓝、深蓝两级色块表现折纸结构，小船居中，四周留出充足透明空间，缩小时仍能辨认轮廓。
背景完全透明，轮廓干净。不要添加文字、字母、实体背景、棋盘格、场景或投影。
```

Image API 设置片段：

```json
{
  "model": "gpt-image-2.5-flare",
  "size": "1024x1024",
  "quality": "low",
  "background": "transparent",
  "output_format": "png"
}
```

这是草案起点，不是已执行请求。生成后检查 alpha 和缩小后的轮廓；PNG 不使用 `output_compression`。

## 5. 已给数据的信息图

用户：

> 做一张 16:9 教学用柱状图提示词，数据是虚构练习：一月阅读 24 小时，二月 36 小时，三月 30 小时。标题为“阅读时长练习”。

交付：

```text
制作一张 16:9 横向教学柱状图，标题“阅读时长练习”位于顶部并出现一次。白底，深蓝柱体，统一无衬线中文字体，布局清楚，有足够留白。

横轴依次标注“一月”“二月”“三月”，对应阅读时长分别为 24、36、30 小时。纵轴从 0 开始，以小时为单位，使用等距刻度，柱高准确对应给定数值；每根柱子顶部各标出对应的数字。保留完整坐标轴和全部标签。

底部清楚标注“虚构数据，仅用于教学练习”。不得添加第四个月、额外统计值、趋势结论或来源引用。
```

验收重点：纵轴、柱高、数值、单位和练习声明都要检查；不能因排版清晰就认定数值准确。

## 6. 根据文字重复反馈修正

用户反馈：

> 上一张图标题出现了两次，其他都满意。只给下一轮编辑提示词。

交付：

```text
以上一张生成结果为编辑输入，只修正重复标题：保留原文字区中的主标题，删除重复出现的那一处标题，使主标题在整张图中只出现一次。保留主标题原文、原文字区的字体与排版，不重新措辞。
保持产品、背景、构图、颜色、副标题及其他已经正确的细节不变。删除处按周围背景自然补全，不留下残字，不添加新的文字。
```

边界：这是按用户反馈编写的指令，未代表已经看图或修复成功。若实际两处标题无法辨别应保留哪处，查看图片后指定位置或澄清一次。
