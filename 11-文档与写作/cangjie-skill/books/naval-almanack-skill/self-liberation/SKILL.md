# 自我解放：期望、愤怒与自由

## R — 原文 (Reading)

> 如果你伤害别人是因为他们对你有期望，那是他们的问题。如果他们和你有约定，那就是你的问题。……愤怒是一种尽可能强烈地向对方表明你有能力使用暴力的方式。愤怒是暴力的前兆。……生活水平远远低于自己经济收入的人，享受着忙于改善生活方式的人无法理解的自由。
>
> — 纳瓦尔·拉维坎特, 《纳瓦尔宝典》 第二章·幸福

## I — 方法论骨架 (Interpretation)

自由的定义会从「享有自由」（想做什么就做什么）升级为「免于自由」（免于被迫反应、免于愤怒、免于被迫做事）。
三个可操作的解放源：
① **期望边界**——区分「期望」和「约定」：约定（合同/债务/承诺）必须守，期望（别人脑内剧本）不是你的问题；「勇气是不在乎别人的想法」；
② **愤怒解体**——愤怒是与自己签订的契约（身心混乱直到现实改变），也是暴力的前兆；它先伤害握煤的人自己；
③ **就业自由**——生活水平低于收入的人才有说「不」的底气；尝到自由的滋味，可能会让你失业，但那是自由的代价。
时间是最硬的边界：珍惜时间高于一切，不在不想做的事/取悦别人上花时间。

## A1 — 书中的应用 (Past Application)

### 案例 1: 不再为小事愤怒
- **问题**: 年轻时把愤怒当力量（「在我年轻充满睾丸的时候」）
- **方法论的使用**: 把愤怒定义为热煤/暴力前兆，从生活里剔除愤怒者
- **结论**: 「愤怒是你握在手里的一块热煤炭，等着把他扔给别人」
- **结果**: 愤怒不再是核心价值观

### 案例 2: 低生活成本的自由
- **问题**: 如何拥有说「不」的能力
- **方法论的使用**: 保持生活水平低于收入
- **结论**: 「生活水平远远低于自己经济收入的人，享受着忙于改善生活方式的人无法理解的自由」
- **结果**: 财务缓冲=话语自由

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被家人/老板/社会的期望绑架：「他们觉得我应该……」
2. 经常愤怒：「我控制不住生气」
3. 不敢拒绝：「怕得罪人，总在取悦别人」
4. 想辞职但不敢：「被工作困住了怎么办」

### 语言信号

- "他们对我的期望压得我喘不过气"
- "我总是忍不住生气"
- "怎么拒绝别人/怎么说不"
- "expectations / anger / how to say no / freedom"

## E — 可执行步骤 (Execution)

1. **拆分期望与约定**
   - 完成标准: 列出你感到压力的所有「应该」，逐个标注「约定（要守）」或「期望（别人的问题）」

2. **做一次期望断舍离**
   - 完成标准: 挑 1 个纯期望，明确告诉对方「这是你的期望，不是我的约定」；或直接停止迎合
   - 判停条件: 若涉及真实合同/债务/承诺，先履行约定再谈自由

3. **愤怒检查**
   - 完成标准: 下次愤怒触发时，暂停并写下「我在生什么气？这值得我支付身心混乱吗？」

4. **检查就业自由缓冲**
   - 完成标准: 计算支出/收入比；若接近 1:1，制定 3 个月降支计划（为自由买期权）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 真实违约/负债场景（约定必须守，别用「期望论」自我开脱）
- 工作中不能立即辞职的人（先建缓冲，再谈就业自由）

### 作者在书中警告的失败模式

- 把「期望」当「约定」: 守错合同会耗尽自己
- 用愤怒做谈判工具: 愤怒=暴力前兆，先伤己再伤人

### 作者的盲点 / 时代局限

- 「别人的期望不是你的问题」在家庭/集体文化中的执行成本被低估
- 作者有财务安全网；无缓冲者直接说「不」可能失业

### 容易混淆的邻近方法论

- `honesty-communication`: 拒绝别人时，本 skill 给边界，诚实 skill 给表达方式
