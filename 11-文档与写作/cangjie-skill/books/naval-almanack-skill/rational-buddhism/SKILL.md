# 理性佛教：验证一切

## R — 原文 (Reading)

> 尝试一切，亲自测试，保持怀疑，保留有用的，舍弃没用的。……理性的部分意味着我必须与科学和进化和解。我必须拒绝所有我不能验证的内容。……如果我无法验证它，或者如果我不能通过科学到达那里，那么它可能是真的，也可能是假的，但它肯定是无法证伪的，所以我不能将它视为基本真理。
>
> — 纳瓦尔·拉维坎特, 《纳瓦尔宝典》 第二章·幸福

## I — 方法论骨架 (Interpretation)

「理性佛教」是用科学标准过滤、保留内在技术的精神立场：
① **可证伪底线**——「如果不能做出可证伪的预测，那它就不是科学」；无法验证/无法证伪的主张（业报、脉轮、超能力）不能进入基本真理；
② **亲自测试**——冥想对你有好处吗？理清思路是好事吗？亲自验证后再采纳；
③ **保留有用的**——冥想、观察、接纳等经时间考验的内在工作方法与科学并不冲突；
④ **进化是约束原则**——进化论解释人是什么（生存与复制机器），佛教解释内在状态怎么调，二者可调和；
⑤ **保持怀疑但不关闭体验**——「我不赞成任何幻想的东西」，但也别因「听起来玄」就拒绝亲测（读《当下的力量》的例子：先合上书说屁话，后来带着积极心态尝试，感觉很好）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 拒绝不可验证的教义
- **问题**: 佛教里的业报/脉轮该信吗
- **方法论的使用**: 「我看过。我不记得任何前世。我没有任何相关记忆。我就只是不能相信。」
- **结论**: 无法亲自验证=不能视为基本真理
- **结果**: 保留佛教的内在工作，拒绝玄学部分

### 案例 2: 读《当下的力量》的转变
- **问题**: 对能量练习的第一反应是「这是屁话」
- **方法论的使用**: 「我会带着积极的心态去做。我躺下，并尝试冥想。」
- **结论**: 「很好，如果我相信它，或许它能起作用」
- **结果**: 体验很好——验证优先于偏见

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对玄学/灵修/伪科学主张：「这个该信吗」
2. 建立个人验证标准：「我该信什么」
3. 科学与精神之间的摇摆：「科学和冥想冲突吗」
4. 想尝试但保持理性：「怎么亲测又不走火入魔」

### 语言信号

- "这东西是真的吗/该信吗"
- "怎么验证一个说法"
- "科学 vs 灵修/冥想"
- "is this true / falsifiable / rational approach to spirituality"

### 与相邻 skill 的区分

- 与 `judgment-training` 的区别: 判断力是通用思考能力；本 skill 是「什么可以信」的验证标准
- 与 `monkey-mind-meditation` 的区别: 冥想是技术，本 skill 是允许/拒绝技术的哲学框架

## E — 可执行步骤 (Execution)

1. **跑可证伪测试**
   - 完成标准: 对主张问「它能做出可证伪的预测吗？失败时我能发现吗？」；不能→标记为「非基本真理」

2. **跑亲自验证**
   - 完成标准: 若主张可体验（冥想/断食/练习），设计一个 30 天亲测计划，记录前后差异

3. **按结果取舍**
   - 完成标准: 保留有用的（可复现体验），舍弃没用的（无效果/无法验证），不因来源迷信也不因标签拒绝

4. **写入个人原则**
   - 完成标准: 形成 3 条自己的「相信清单」，注明每条的证据等级

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户寻求宗教/灵性安慰的临终关怀、哀伤场景（尊重信仰选择，不灌输理性主义）
- 用「可证伪」标准审判一切人文领域（文学/爱/意义不适用该标准）

### 作者在书中警告的失败模式

- 把无法证伪当真理: 脉轮、业报等「花里胡哨的命名」不能进入基本真理
- 迷信权威替代亲测: 一切都要亲自测试

### 作者的盲点 / 时代局限

- 「亲自验证」本身也是主观证据，作者对玄学用可证伪标准、对自己体验用个人标准，存在双标
- 理性主义框架对非理性需求的解释力有限

### 容易混淆的邻近方法论

- `judgment-training`: 可证伪性是判断力心智模型库之一
