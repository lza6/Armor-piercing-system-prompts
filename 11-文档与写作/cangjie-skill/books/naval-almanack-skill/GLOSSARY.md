# GLOSSARY — 《纳瓦尔宝典：财富与幸福指南》

> 全书共享术语词典。所有 skill 统一按本书的「作者用法」理解这些词，不使用字典义。
> 完整候选与出处见 [candidates/glossary.md](./candidates/glossary.md)

| 术语 | 作者的用法 | 和常识的差异 | 主要使用 skill |
|---|---|---|---|
| 财富 | 睡觉时仍在赚钱的资产：企业、股权、代码、媒体、可出租房产 | ≠ 钱/存款；财富是资产，金钱是信用媒介 | wealth-structure, productize-yourself |
| 金钱 | 转移财富的媒介、社会的信用符号 | ≠ 财富；可调用他人时间 | wealth-structure |
| 特殊知识 | 不可培训、不可替代的知识，来自 DNA+环境+个人回应 | ≠ 专业技能/热门技能；对你像玩对别人像工作 | productize-yourself |
| 杠杆 | 放大判断力的工具：人力 / 资本 / 零边际复制成本产品 | 代码/媒体无需许可最民主；不创造价值只放大 | wealth-structure, productize-yourself |
| 判断力 | 知道行为长期后果并据此做正确决定的能力 | ≠ 聪明；方向选择 > 努力速度 | judgment-training |
| 责任（责任感） | 以个人名义押上声誉、公开承担失败风险 | ≠ 尽责；是换取产权与杠杆的抵押 | wealth-structure |
| 地位游戏 | 等级排名中的零和游戏 | ≠ 财富游戏（正和）；赢家必须击倒别人 | game-selection |
| 复利 | 财富、知识、关系、声誉的指数积累规律 | ≠ 只是金融概念；「所有好处都来自复利」 | long-term-compounding |
| 产品化你自己 | 独特性 × 规模化（杠杆）的致富总纲 | ≠ 个人品牌营销 | productize-yourself |
| 委托-代理问题 | 利益归属决定行为质量：委托人在意、代理人自利 | ≠ 管理问题；解法是绑收益而非加监督 | principal-agent |
| 个人时薪 | 高得离谱的自我估值与时间分配判据 | ≠ 真实薪资；低于时薪的事外包/不做 | hourly-rate-time |
| 心猴 / 猴子思维 | 不受控制的焦虑内心独白（失控程序） | ≠「我的想法」；90% 出于恐惧 | monkey-mind-meditation |
| 欲望契约 | 欲望=与自己的约定：得到前不快乐 | ≠ 动力；同时只留一个重大欲望 | happiness-skill |
| 幸福 | 什么都不缺的默认状态，本质是平和 | ≠ 快乐/狂喜；靠减法而非加法 | happiness-skill |
| 接受 | 改变/接受/离开三选项之一的主动选择 | ≠ 认命；快速接受=快速适应 | acceptance |
| 理性佛教 | 以可证伪/亲测为底线、保留佛教内在技术 | ≠ 宗教；拒绝不可证伪教义 | rational-buddhism |
| 退休 | 不为想象中的明天牺牲今天的当下状态 | ≠ 65 岁领退休金；三条路径 | hourly-rate-time |
| 内在记分卡 | 无外部进度条的内在自我标准 | ≠ 名声/排名；人生是单人游戏 | game-selection |
