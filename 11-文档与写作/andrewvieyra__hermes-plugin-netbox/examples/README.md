# Examples

Each file is a ready-to-use `operations` payload for `netbox_plan`. Ids and slugs refer to a
fresh [netbox-docker](https://github.com/netbox-community/netbox-docker) demo instance; adjust
them for yours. Try one with the slash command inside a Hermes session:

```
/netbox status
```

then ask the agent, for example: "Plan the change in examples/bulk-status.json and show me the diff."
