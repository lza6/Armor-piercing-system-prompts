# 马想运营文案 Skill

一套面向焦点图、广告位、商品详情页和图文广告页的运营文案生产与品控方法。

它解决的不是“怎样写出文学级文案”，而是怎样让运营团队稳定写出目标明确、对象具体、利益清楚、能够推动行动的合格文案。

## 时代背景与适用范围

这套方法源自马想在约 2016—2022 年负责得到 App 运营工作期间的总结，原始方法沉淀于《运营文案的“答案”之书》。当时主要面对的媒介环境是图片广告、焦点图/广告位，以及图文混排的商品详情页/图文广告页。

请注意：

- 它可能不适合其他公司，使用时需要结合具体品牌、产品、用户和渠道调整。
- 它形成于短视频全面崛起之前，不以短视频“黄金三秒”为主要问题背景。
- 用于短视频时，可以借用对象、利益、证据、行动等底层判断，但不要机械套用标题字数、页面层级和清单体规则。

## 核心方法

- 三大纪律：目标感、对象感、情绪感。
- 从“我是什么”转向“我对你有什么用”。
- 先判断办法和看法，再打磨说法。
- 用 4U 检查针对性、迫切性、独特性和有用性。
- 焦点图/广告位负责吸引和传播；商品详情页/图文广告页负责可信、情感和理性的说服。
- 用八项注意和底线价值观完成上线前品控。

## 使用

将仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/malulile-sudo/ma-operations-copywriting.git ~/.codex/skills/ma-operations-copywriting
```

之后可以这样调用：

```text
使用 $ma-operations-copywriting 审核并改写这份运营文案，先给能不能上的结论。
```

Skill 会根据任务按需读取：

- `SKILL.md`：核心判断、工作流程和交付格式。
- `references/review-checklist.md`：三大纪律、八项注意、说服结构和底线检查。
- `references/idea-bank.md`：没有角度或需要多版本时使用的创意角度库。
