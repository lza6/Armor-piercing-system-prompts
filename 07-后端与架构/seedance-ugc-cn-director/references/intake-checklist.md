# Intake Checklist

Use this file when the user asks for a Seedance UGC director plan but has not provided the blocking production decisions.

## 判断是否可以继续

阻塞项只有 3 项。缺任意一项，且用户没有明确说“你来定 / 跳过确认 / 直接按默认做”，先不要生成完整方案：

1. 投放国家/地区
2. 成片口播语言
3. 是否已有固定达人/模特/参考形象

非阻塞默认项：

- 发布平台：用户没有主动提及时，默认 TikTok。
- 视频时长：用户没有主动提及时，默认 15 秒。
- 视频声音/画面形式：用户没有主动指定时，不要追问；必须自动学习最近半个月 TikTok 相关服装类带货视频中销量好、转化率较高的视频形式，再结合该服装的品类、版型、材质/纹理、颜色、可见细节、穿搭场景、购买动机、市场、达人/模特和时长自动选择。

## 创作前必须确认的事项

请先确认下面 3 件事；平台、视频时长、视频声音/画面形式如果未提供，我会按非阻塞默认规则处理：

1. **投放国家/地区**  
   你要投放哪个国家或地区？  
   示例：美国、英国、德国、法国、东南亚、日本、中东、中国大陆等。

2. **成片口播语言**  
   你希望成片说什么语言？  
   示例：美式英语、英式英语、中文、德语、法语、西语、阿拉伯语。当前 PopBoom schema 1.4 服装带货流程要求每个卖点动作都有对应短口播，不支持“无口播只配生成字幕”；若用户明确要静音版，应另做非付费/后期字幕流程，不能冒充通过当前提交门。

3. **是否已有固定达人/模特/参考形象**  
   你是否已有固定达人、模特或参考形象？  
   如果没有，请说明“没有固定达人”，我会设计虚拟达人形象。

如果你不想逐项回答，也可以直接回复：“你来定”、“跳过确认”或“直接按默认做”。

## 自动学习与形式选择

只要调用 $seedance-ugc-cn-director 生成服装/电商 UGC 方案，就必须自动学习最近半个月 TikTok 相关服装类带货视频中销量好、转化率较高的视频形式。这个动作不需要用户额外提出。

如果用户没有主动指定视频声音/画面形式，应结合：

- 最近半个月 TikTok 服装带货学习结果
- 用户提供的衣服/产品证据
- 投放国家/地区
- 发布平台，默认 TikTok
- 口播语言
- 达人/模特信息
- 视频时长，默认 15 秒

自动选择最适合这件服装的声音/画面形式，并据此写脚本、Seedance 提示词、第 12 条促单文案与热门标签。选择时必须明确匹配该服装的品类、版型、材质/纹理、颜色、可见细节、穿搭场景和购买动机。

市场必须先于创意形式锁定。美国/美式英语使用 `us_champion_v1`，德国/德语使用 `de_champion_v1`；美1、美2、美3、德1、德2、德3已经自带市场和语言，不再重复询问。随后依据 `market-prompt-compiler-contract.md` 固定 `prompt_shell_mode`、`delivery_mode`、`camera_mode`、`music_mode`、`verdict_mode`、`commerce_cta_mode` 和 `screen_text_policy`，再选择基础模板。不能先完成一个市场的脚本再整段翻译到另一个市场。

写脚本前还必须把每个入选卖点登记为“证据来源—服装部位/效果—匹配景别—展示动作—左右手轨迹—`proof_endpoint`—同一目标的市场语言口播”。每个口播 beat 还要写明 `spoken_language`，并在独立 `voiceover_review` 中提供市场原文和中文审稿翻译；中文只用于审核，绝不能进入生成提示词、音频或屏幕。图片能证明版型、结构、颜色和可见纹理，但不能单独证明弹力、透气、凉感、防水或抗皱；缺少此类性能证据时不要阻塞流程，改选有画面证据的卖点和动作。

当用户提供 Amazon URL 或要求分析评价时，URL 本身不是事实。写脚本前必须执行 `amazon-product-review-evidence-contract.md`：锁定请求 URL、父/子 ASIN 和选中颜色/尺码；将结构化属性、卖家文案、直接评价、买家图片、Amazon AI 摘要和第三方摘要分开；记录实际读过的 review ID、评价变体与买家图是否真实目检；建立“痛点—证据—独立解决卖点—claim/evidence ID—镜头动作”映射。

Amazon 商品页或评价不可达不是视觉脚本的阻塞项，但必须把研究状态标成 `partial` 或 `blocked`，删除所有未取得的 Amazon/评价衍生断言，再用可见参考和用户事实继续。不要用搜索片段、AI摘要、第三方页面、相似 ASIN 或同父款另一子 ASIN 填补成当前变体事实。若直接评论或买家图对用户目标不可缺少，请让用户在 Chrome 完成登录/验证码或提供截图。

## 不要做

- 不要因为用户没说发布平台就停止；默认 TikTok。
- 不要因为用户没说视频时长就停止；默认 15 秒。
- 不要因为用户没说视频声音/画面形式就停止；自动学习并自动选择。
- 不要默认美国市场，除非用户授权或产品证据明显指向，并且必须标注为工作假设。
- 不要替用户确定口播语言，除非用户授权。
- 不要把美区完整提示词翻译成德语，或把德区完整提示词翻译成英语；必须从共同证据与动作计划重新走目标市场编译器。
- 不要把销冠语料的重复频率当作因果结论，也不要把原始 Excel、完整原始提示词、统计或内部分析放进生产提示词。
- 不要编造销量、转化率、评价数、折扣、认证、医疗/健康功效或物流承诺。
- 不要把页面总 ratings 当成实际读取评论数，不要把一条评论写成“很多买家”，不要让卖家文案或评论摘要冒充直接买家评价。
- 不要让模特伪称自己购买、穿过或测试过商品，除非存在真实测试证据或用户明确授权。
- 不要在护理、尺码、材质、弹力等来源冲突时挑选更好卖的一条；标记冲突并从绝对脚本/Caption 中移除。
- 不要为了增加动作而让模特无依据拉扯衣服或暗示弹力；也不要为了防止肢体错误而删掉所有展示动作。每拍只做一个正确动作，并明确两只手的起点、职责和终点。
