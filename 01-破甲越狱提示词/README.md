# 破甲越狱提示词

针对各主流大模型的越狱/破限提示词合集（L1B3RT4S 系列等），按模型厂商分文件。

## 内容

| 目录/文件 | 说明 |
|-----------|------|
| [`jailbreak-prompts/`](./jailbreak-prompts) | 按厂商拆分的破甲提示词文件（`L1B3RT4S_*.mkd` 系列 + 红队系统提示词），覆盖 Anthropic、OpenAI、Google、Meta、Microsoft、DeepSeek、Grok、Cursor、Perplexity、Nous、Brave 等 |

## 使用提示

- 这类提示词用于研究模型的对齐行为与提示词鲁棒性，请在合规与授权的范围内使用。
- 文件名中的厂商名表示该提示词**针对的目标模型**。
