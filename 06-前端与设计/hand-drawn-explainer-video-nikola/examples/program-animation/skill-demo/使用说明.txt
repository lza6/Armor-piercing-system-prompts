这是已通过的 36 秒手绘动效工程示例，包含 8 个镜头、完整案例旁白与可编辑 SVG 元素。
不要将其固定文稿和时长用于所有新视频。可参考人物手臂、气泡、卡片收拢、流程箭头与闭合权限锁。
需要 Node.js、HyperFrames 0.8.20、可工作的完整 FFmpeg/FFprobe 与渲染浏览器。
在工程目录先运行 npm install，再运行 npm run check，检查后 npm run render。首次安装可能联网下载指定版本。
GSAP 由 npm 安装并复制到 assets，不随仓库提交；中文字体依赖系统 Microsoft YaHei，可替换为已获授权的字体并重新检查布局。
本工程不包含密钥。附带旧音频只用于此示例，不调用新的配音接口。
配音是原文完整合成，字幕按句间停顿估算，并非逐字强制对齐。
