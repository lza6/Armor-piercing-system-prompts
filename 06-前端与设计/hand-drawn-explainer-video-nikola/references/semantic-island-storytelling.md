# 分段边画边讲：语义岛叙事

当用户要“画一部分讲一部分”“先左后右”“娓娓道来”，并希望穿插关键词、数字或短标签时，使用本页。目标不是把一页切成卡片，而是让同一幅画中的两个独立叙事事件按旁白先后自然完成：第一部分落墨、上色并短暂停留，随后第二部分开始，先画内容继续保留。

## 何时使用

- 一句话内存在清楚的“起因 → 结果”“过去 → 后来”“人物 → 产品”等两阶段关系；
- 两个阶段各自能形成一个完整小场景，且放在同一横向画布有自然空间关系；
- 旁白能为每个阶段提供至少约 2.5–4 秒可见绘制时间。

不要机械套用：单一人物动作或单一事件使用一幅完整场景；三个以上独立事件通常拆幕；流程卡片、关系图和独立知识元素转到程序动画模式。

## 1. 先做声音预算，再决定画多少

`hand-follow` 只平滑手部显示位置，不会减慢笔迹。实际观感由“区域可用时长 ÷ 线条与色块复杂度”决定。先得到真实音频，再为每个语义区划出：

1. 落墨与主要轮廓；
2. 有限平涂；
3. 完成后的凝视时间，建议至少 0.5 秒；
4. 关键词出现窗口（如需要）。

若代表区域在正常速度下仍像赶工，按以下顺序处理：延长或重分旁白时间 → 减少小零件、排线和纹理 → 缩小区域承载内容 → 拆成下一幕。不要只降低 `hand-follow`，也不要降帧掩盖问题。

常见需简化的素材包括：电路板针脚、木纹、书页小字、屏幕伪文字、人群五官、密集阴影和重复装饰线。源图的“细节更多”并不等于动画效果更好。

## 2. 双语义岛生图约束

16:9 横屏默认可从下面的结构起步，再根据故事调整：

- 左、右各一个完整叙事岛，主体比例相近；
- 中间保留画面宽度约 6%–10% 的空白沟槽；
- 底部约 18% 保持干净，供字幕使用；
- 岛之间不出现跨区地面线、电线、桌边、阴影、箭头、飘带或相连轮廓；
- 白色或暖米白纸张，清晰深色墨线，有限平涂，低纹理；
- 图片中不生成中文、日期、公司名、Logo、屏幕内容或需要准确拼写的产品名。

提示词骨架：

```text
横向 16:9 手绘故事插画，同一张纸上只有两个相互独立但叙事连续的场景岛。
左侧：[第一阶段的人物、动作、必要道具]。
右侧：[第二阶段的人物、动作、必要道具]。
中间保留 6%–10% 纯净纵向留白；两个岛之间没有地面线、电线、桌边、阴影、箭头或任何轮廓连接。
底部 18% 保持干净用于字幕。自然肤色 Q 版人物，清晰墨线、有限平涂、低纹理、少量强调色。
不要文字、数字、Logo、伪字、密集排线、小零件和摄影质感。
```

每张图返回后立即保存并实际查看。内置图像生成在同一任务中优先逐张调用；不要用并行批量生成换取速度，因为长时间无中间结果时既难恢复，也容易重复付费。发现伪字、角色年龄错误或线条过密时，只编辑当前图，不重做已经批准的其他场景。

## 3. 标注与时序

每个岛至少对应一个语义区域。区域框落在空白沟槽内，不能切脸、手和关键道具。先运行 `check_drawable_regions.py`；重叠、跨区连通线和留白不足应修复，不把警告当作装饰性提示直接忽略。

时序遵循：

```text
左岛落墨 → 左岛上色 → 左岛完成停留 → 左关键词（可选）
→ 右岛落墨 → 右岛上色 → 右岛完成停留 → 右关键词（可选）
```

右岛开始前必须完全不可见；右岛开始后左岛持续保留。`protectedRegions` 只处理少量不可避免的遮挡，不能用来挽救跨岛相连的构图。

## 4. 关键词与准确文字

关键词使用确定性 ASS/HTML 文字层，不交给图片模型。一般为 2–6 个汉字或一个准确英文产品名，放在中间留白、上方空区或已完成岛附近。采用逐字显现或短标记线即可，避免大标题盖住人物。

在 ASS 中可使用逐字 `\kf` 或等价的打字式揭示。文字层要和旁白含义同步，并检查：不覆盖人物表情、不进入底部字幕区、不与下一岛的绘制区域碰撞。

## 5. 推荐起步参数与代表镜头

对于“16:9、双语义岛、低纹理 Q 版人物”的稀疏场景，可从以下范围制作代表镜头：

```text
--ink-path skeleton --color-fill contour-wipe
--hand-follow 0.25 至 0.30
--hand-height 220 至 260
```

这只是该构图的起点，不是全局默认。正式全片前先连续播放一个含两个岛的 8–12 秒代表镜头，检查第一岛完成、第二岛开始、大范围转向、补色和关键词显现；只有通过后才复用参数批量渲染。

## 6. 故事节奏

人物传记和知识故事优先用“冲突或问题钩子 → 回到起点 → 转折 → 结果或价值”的结构。钩子不是夸张标题，而是用一个可核验的矛盾让观众愿意继续听。时长允许时，不要为了压到 20 秒把每个岛都画成高速草稿；宁可在 60 秒内让关键节点完成并被看清。

## 7. 必查画面

除通用联系表外，至少抽取并查看：

- 每个岛完成前约 0.2 秒；
- 下一岛开始后约 0.2 秒；
- 每个场景切点前后各 3 帧；
- 最终视频最后 0.3–0.5 秒；
- 每个关键词显现中段和完成帧。

自动媒体检查无法判断“源图在片尾突然放大叠入”、语义岛提前泄漏或关键词压脸，因此这些检查必须看真实帧，不能只看退出码。
