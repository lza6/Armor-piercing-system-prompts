## 核心流程

```text
宝宝照片＋主题与画风
→ AI 生成文案和分镜
→ 生成场景参考图提示词
→ 手动生成并确认参考图
→ 生成图生视频提示词
→ 手动生成各段视频
→ 生成配音和配乐提示词
→ 拼接并导出完整成片
```

它不是一键生成工具，而是一个会记住前面选择、每次只推进一步的制作向导。

## 用户需要准备什么

- 一张清晰的孩子照片
- 视频用途，例如生日、节日、成长纪念或鼓励
- 想要的画风、画面比例和大致时长
- 一个简单故事想法；没有想法也可以让 Skill 帮忙提案

## Skill 和用户分别做什么

| Skill 负责 | 用户负责 |
|---|---|
| 询问并整理制作需求 | 提供照片并选择方向 |
| 写文案、分镜和各阶段提示词 | 在自己选择的工具中生成素材 |
| 根据返回结果指出需要修改的镜头 | 确认孩子形象、故事和最终效果 |
| 给出配音、配乐和剪辑清单 | 拼接、检查并导出成片 |

## 什么时候需要用户介入

1. 开始时：上传照片，选择用途、画风、比例和时长。
2. 文案完成后：确认故事和三个分镜。
3. 生图提示词完成后：手动生成参考图并发回来。
4. 视频提示词完成后：手动生成各段视频并发回来。
5. 音频提示词完成后：生成配音和配乐。
6. 最后：按剪辑清单拼接、检查并导出。

## 使用方式

把这个目录复制或链接到支持 Agent Skills 的 Skills 目录，然后输入：

```text
使用 $kids-blessing-video-wizard，带我用一张孩子照片制作一个30秒的生日祝福动画视频。
```

核心流程见 `SKILL.md`。
