## 各分类说明

### 破甲越狱提示词

针对各主流大模型的越狱/破限提示词合集（L1B3RT4S 系列等），按模型厂商分文件。

### 厂商系统提示词

从各家 AI 产品中提取的系统提示词原始文本，按厂商/产品归档，用于研究提示词工程与模型行为。

### 逆向工程

二进制分析、反编译、动态调试、脱壳、协议逆向、移动端逆向（Android/iOS）、固件与游戏客户端逆向等技能。

### 安全渗透

渗透测试、红队/蓝队、漏洞挖掘、CTF、取证与事件响应、威胁情报、云安全、Web/网络安全测试等技能。

### 技能与代理开发

Claude Code / Codex 等代理体系的 Skill、Agent、Command、Hook、Plugin 与 MCP 服务开发技能。

### 前端与设计

React/Vue/Svelte/Next.js、CSS 与 Tailwind、设计系统、动效、无障碍、UI/UX 相关技能。

### 后端与架构

API 设计、微服务、数据库、消息队列、系统设计、领域驱动设计、重构与代码质量相关技能。

### 移动开发

Android、iOS/SwiftUI、Flutter、React Native、鸿蒙与小程序等移动端开发技能。

### 数据与人工智能

机器学习、深度学习、LLM/RAG、向量检索、微调、数据科学、MLOps 与模型部署相关技能。

### 运维与云原生

DevOps、Kubernetes、Docker、Terraform、CI/CD、云平台（AWS/Azure/GCP）、可观测性与 SRE 技能。

### 文档与写作

技术文档、Office 文档处理（Word/Excel/PPT/PDF）、写作润色、翻译本地化与内容编辑技能。

### 商业与营销

SEO、增长、广告投放、品牌、销售、CRM、定价与商业模式相关技能。

### 金融与交易

### 产品与项目管理

产品需求（PRD）、敏捷/Scrum、路线图、用户故事、OKR 与项目排期相关技能。

### 内容创作与社媒

### 角色扮演与人格

## 关于来源与整理

- 素材来自公开的开源仓库合集，经**跨仓库内容哈希去重**（同一文件只保留一份）。
- 仅收录提示词与配置类文本文件（`.md` / `.json` / `.yaml` / `.txt` 等），不含视频、图片、字体与二进制。
- 每个技能单元的原始来源仓库记录在 [来源清单.md](./来源清单.md)。
- 版权归各原始作者所有，仓库内保留原始 `LICENSE` 声明；请遵循各来源仓库的许可条款使用。
