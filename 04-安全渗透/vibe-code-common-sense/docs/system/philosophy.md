# Philosophy

Vibe coding is not the problem.

Untracked vibe coding is the problem.

The system is built around a practical belief:

```text
Treat every AI coding agent as dumb until the project proves otherwise.
```

That means:

- give it context;
- give it constraints;
- give it a checklist;
- require evidence;
- track every merge.

Good vibes. Better engineering. Real results.
