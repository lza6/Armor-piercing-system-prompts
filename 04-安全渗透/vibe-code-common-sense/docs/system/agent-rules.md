# Agent Rules

The root `AGENTS.md` tells future agents how to behave.

Minimum rules:

1. Read `docs/PRODUCT_TIMELINE.md` before starting.
2. Build the first unchecked item unless the user overrides it.
3. Keep PRs small.
4. Do not invent architecture silently.
5. Run verification before claiming completion.
6. Update the tracker after opening a PR.
7. Show the next unchecked item.

The point is not to make the agent slow. The point is to stop wasted speed.
