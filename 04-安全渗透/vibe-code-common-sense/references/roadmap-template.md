# Roadmap

This roadmap describes product direction. Use
[`docs/PRODUCT_TIMELINE.md`](./PRODUCT_TIMELINE.md) for PR-level tracking.

## Milestone 0: Project Rails

Goal:

> Make the project clear enough for humans and agents to work safely.

Expected outcomes:

- README explains the idea and status.
- Project blueprint defines goals and non-goals.
- Product timeline tracks PR-sized work.
- Agent instructions define working rules.
- Architecture doc captures first boundaries.

## Milestone 1: MVP Skeleton

Goal:

> Create the smallest runnable product shape.

Expected outcomes:

- Project can run locally.
- First smoke test exists.
- First user workflow is visible.
- Docs explain current limitations.

## Milestone 2: Useful MVP

Goal:

> Make the first workflow useful for the first user.

Expected outcomes:

- Core workflow has validation and error states.
- Output is understandable.
- Tests cover the main behavior.
- Known gaps are documented.

## Later

- Integrations.
- Hosted features.
- Collaboration features.
- Public launch packaging.
