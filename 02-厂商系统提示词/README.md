# 厂商系统提示词

从各家 AI 产品中提取的系统提示词原始文本，按厂商/产品归档，用于研究提示词工程与模型行为。

## 内容来源

| 目录 | 文件数 | 说明 |
|------|-------:|------|
| [`system_prompts_leaks/`](./system_prompts_leaks) | 420 | 按厂商归档的系统提示词泄露集（Anthropic、OpenAI、Google、Meta、Mistral、DeepSeek、xAI、Kimi、GLM、Notion、Cursor 等） |
| [`claude-code-system-prompts/`](./claude-code-system-prompts) | 711 | Claude Code 各系统提示词与工具描述，逐条拆分，便于按功能检索 |
| [`system-prompts-and-models-of-ai-tools-中文版/`](./system-prompts-and-models-of-ai-tools-中文版) | 378 | 各 AI 工具系统提示词的中文翻译版，含厂商名中文目录 |
| [`x1xhlol-system-prompts-and-models/`](./x1xhlol-system-prompts-and-models) | 104 | 各 AI 工具与模型系统提示词合集（Cursor、Devin、Manus、Lovable、Windsurf 等） |
| [`CL4R1T4S/`](./CL4R1T4S) | 70 | CL4R1T4S 系列，按厂商大写目录归档 |
| [`claude-code-prompts-master/`](./claude-code-prompts-master) | 43 | Claude Code 相关提示词集合 |
| [`awesome-system-prompts/`](./awesome-system-prompts) | 21 | 按 LLM / Agents 两类归档的提示词汇总 |

## 使用提示

- 内容为**历史快照**，厂商会持续更新提示词，引用时请标注抓取时间。
- 中文版目录名中的括号内为厂商英文名（例如 `Anthropic（Claude）`）。
